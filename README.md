# MV Prompt Studio 🎬

把一个想法、一段故事、一篇小说，变成一整套**可以直接复制粘贴去出图出片**的 MV 制作提示词——歌词、人物、场景、道具、9/12 宫格分镜、逐段视频提示词，一条龙全部落盘成结构化项目文件夹。

遵循 [Agent Skills](https://skills.sh) 开放格式（`SKILL.md`），装上就能用。

## 安装

```bash
npx skills add bseazh/MV-studio
```

也可以用完整仓库地址：

```bash
npx skills add https://github.com/bseazh/MV-studio
```

手动安装：把本仓库克隆到你的 agent skills 目录（例如 `~/.agents/skills/mv-prompt-studio`），保持 `SKILL.md` 在该目录根部即可。

## 它解决什么问题

用 AI 做 MV，最难的不是单个提示词，而是**让几十条提示词互相咬合**：人物不串脸、场景不漂移、道具状态连贯、每段视频接得上上一段。本 skill 把这条链工程化了：

| 环节 | 做法 |
|---|---|
| 立项 | 问答引导确认参数，**每个问题都带推荐值**，说「都按推荐来」直接走完全程 |
| 素材 | 贴几百字故事/小说/日记，先提炼成「核心情绪/人物/转折」确认表再动工 |
| 画风 | 全局锁：定稿后原文注入之后每一条提示词的首尾，保证全套图风格统一 |
| 一致性 | 人物身份板 / 场景锚点图 / 道具图作为参考图，用 `[图N·名字]` 槽位机制在提示词里精确引用 |
| 分镜 | 9/12 宫格黑白铅笔草图，节拍由剧情驱动，跨段连续性有「入场承接/出场钩子」命脉 |
| 视频 | 每段提示词带【参考图】前置清单 + 分秒节拍表（第 X–Y 秒跟着故事板第 N 格走）+ 参数建议（480p 起步） |

## 快速开始

装好后对 agent 说：

```
帮我做个 MV：一个女孩在雨天的便利店，等一个不会来的人
```

三种典型开局都行：

1. **模糊想法** —— 「帮我做个 MV，讲……」
2. **只有几个词** —— 「赛博朋克 女战士 燃一点的」
3. **现成素材** —— 贴一段几百字的故事说「做成 MV」，它会先提炼再提问

嫌问得多就说「**都按推荐来**」，它填满整张确认单让你扫一眼后开工。

## 两条工作路径

| | 手动模式（默认） | 自动模式 |
|---|---|---|
| 谁出图 | 你自己贴提示词到画布（即梦/可灵/Gemini…） | agent 直接调模型 |
| 交付 | 一次性生成全套提示词 + `复制粘贴/` 纯文本包，照 `0-操作顺序.txt` 逐步贴，**不用中途回来等验收** | 逐张出图给用户确认后再往下 |
| 适合 | 大多数人、任意画布 | 已接好生图 API 的用户 |

手动模式下你拿到的每个 txt 长这样：头部是「上传哪几张参考图、按什么顺序」+ 视频文件的参数建议，分隔线之间是纯净提示词正文，尾部是「存成什么名、放哪、下一步谁用它」。

## 十个阶段

```
0 立项问答 → 1 情节(3选1) → 2 歌词(3选1) → 3 画风锁
     → 4 人物 → 5 场景 → 6 道具 → 7 分镜(9/12宫格) → 8 视频 → 9 交付
```

每阶段产出落盘、状态写进 `进度.json`，随时说「继续我的 MV」断点续做；改前面的阶段会主动告诉你哪些下游产物失效。

## 项目产物结构

```
mv-<项目名>/
├── 进度.json              ← 状态机，唯一事实来源
├── 全部提示词.md           ← 总索引
├── 使用说明.md
├── 1-情节/ ~ 8-视频/       ← 各阶段定稿与提示词
├── 复制粘贴/              ★ 用户主要用这个（0-操作顺序.txt 是入口）
├── 素材/                  ← 出的图和视频（人物/场景/道具/分镜/视频/）
└── 模板/
```

## 目录（本仓库）

```
├── SKILL.md               ← skill 入口（含核心铁律）
├── references/            ← 十个阶段的详细规范（问答/情节/歌词/画风/人物/场景/道具/分镜/视频/交付）
├── scripts/新建项目.py     ← 项目骨架一键创建
└── 使用说明.md             ← 面向使用者的完整说明
```

## 设计铁律（摘要）

1. 先问再生成，参数没核对完不开工
2. 创作主张让用户选，技术参数替用户定
3. 画风是全局锁
4. **参考放最前**：提示词正文用到参考图时，【参考图】清单必须在正文最前面，逐张写明用途
5. **手动模式不等图**：阶段 4→8 提示词一次性生成再交付，验收图片是出图后的可选服务
6. 状态写在 `进度.json`，随时可续做
