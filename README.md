# MV Prompt Studio 🎬

把一个想法、一段故事、一篇小说，变成一整套**可以直接复制粘贴去出图出片**的 MV 制作提示词——歌词、人物、场景、道具、9/12 宫格分镜、逐段视频提示词，一条龙全部落盘成结构化项目文件夹。

遵循 [Agent Skills](https://skills.sh) 开放格式（`SKILL.md`），一条命令装上就能用。

## 安装

> 前置要求：Node.js ≥ 22.20（CLI 用的是 [vercel-labs/skills](https://github.com/vercel-labs/skills)）

```bash
# 最简安装（装到当前项目，交互式选择要装的 agent）
npx skills add bseazh/MV-studio

# 全局安装（本机所有项目都能用）
npx skills add bseazh/MV-studio -g

# 指定安装到某个 agent（支持 Claude Code / Codex / Cursor / OpenCode 等 75+）
npx skills add bseazh/MV-studio -a claude-code

# 用完整仓库地址也一样
npx skills add https://github.com/bseazh/MV-studio
```

装完发生了什么：

- 本仓库根目录就是一个完整的 skill 包（`SKILL.md` 在根），CLI 会把整个目录拷贝到目标位置的 `.agents/skills/mv-prompt-studio/`（`-g` 则装到全局 skills 目录）
- 生成 `skills-lock.json` 记录内容哈希，方便后续比对更新；重复执行同一条命令即可更新
- 本仓库只有一个 skill：`mv-prompt-studio`（名字取自 `SKILL.md` 的 frontmatter）

手动安装（不想用 CLI 时）：把仓库克隆到你的 agent skills 目录，保证 `SKILL.md` 在该目录根部即可：

```bash
git clone https://github.com/bseazh/MV-studio.git ~/.agents/skills/mv-prompt-studio
```

验证安装：对 agent 说「**帮我做个 MV，讲……**」或「**继续我的 MV**」，它会走开场问答。

## 它解决什么问题

用 AI 做 MV，最难的不是单个提示词，而是**让几十条提示词互相咬合**：人物不串脸、场景不漂移、道具状态连贯、每段视频接得上上一段。本 skill 把这条链工程化了：

| 环节 | 做法 |
|---|---|
| 立项 | 问答引导确认参数，**每个问题都带推荐值**（时长推荐 1 分钟左右，说「都按推荐来」直接走完全程） |
| 素材 | 贴几百字故事/小说/日记，先提炼成「核心情绪/人物/转折」确认表再动工 |
| 画风 | 全局锁：定稿后原文注入之后每一条提示词的首尾，保证全套图风格统一 |
| 一致性 | 人物身份板 / 场景锚点图 / 道具图作为参考图，用 `[图N·名字]` 槽位机制在提示词里精确引用 |
| 分镜 | 9/12 宫格黑白铅笔草图，节拍由剧情驱动，跨段连续性有「入场承接/出场钩子」命脉 |
| 视频 | 每段提示词带【参考图】前置清单 + 分秒节拍表（第 X–Y 秒跟着故事板第 N 格走）+ 参数建议（480p 起步） |

## 快速开始

装好后对 agent 说：

```
帮我做个 MV：一个女孩在雨天的便利店，等一个不会来的人
```

三种典型开局都行：

1. **模糊想法** —— 「帮我做个 MV，讲……」
2. **只有几个词** —— 「赛博朋克 女战士 燃一点的」
3. **现成素材** —— 贴一段几百字的故事说「做成 MV」，它会先提炼再提问

嫌问得多就说「**都按推荐来**」，它填满整张确认单让你扫一眼后开工。时长由你拍板：说个具体数（45 秒、2 分半都行），它按每段 15 秒折算段数。

## 核心提示词一览

skill 产出的一切提示词都由下面几个骨架生成。`{{双花括号}}` 是按你的项目填充的槽位。

### ① 参考图槽位写法（所有出图提示词通用）

```
[图N·名字]
```

- 编号 `N` 对应文件头「需要上传的参考图 · 按顺序」清单里的第 N 张，**上传顺序必须和编号一致，传错模型会认错人**
- 名字是给人看的，提示词里的 `[图N·xxx]` 原样保留，不要替换成文件名

### ② 人物身份板提示词（一致性链的锚点）

```
画风：{{画风锁描述}}

创建一张艺术性的 16:9 角色身份板：{{角色名}}，{{外貌/服装/气质关键特征}}。
主格为正面全身定妆照，辅助格展示 {{按剧情需要的 3-4 种情绪状态}} 的表情与姿态变化。
所有格子必须是同一个人、同一套服装、同一画风，供后续分镜与视频当身份锚点引用。
```

### ③ 9/12 宫格分镜提示词（每段一张故事板）

```
{{画风描述}}

【参考图】
[图1·{{场景名}}场景] —— 参考它的空间结构、光线方向、材质、主色调和关键道具。
  环境图只是场景锚点，不要机械复制成静态背景；必须让故事板发生在该图的某个局部区域。
[图2·{{角色名}}身份板] —— 优先参考人物气质与外貌特征，但保持故事板草图应有的简化表达。
[图3·{{道具名}}道具] —— 本段道具状态：{{查道具状态表}}

{{简报①：为故事板创建一个明确的局部区域，专注的核心视觉焦点与情绪基调；
  角色在本段中的状态/情绪}}

16:9 故事板表格，{{9 或 12}} 个电影风格面板。实际故事板绘图必须仅为黑白：
粗糙的铅笔线条、最小细节、快速手势绘图能量、强烈的轮廓可读性，
保持轻量、动态且未完成，就像早期的动作预览。

{{简报②：动作序列 6-8 个节拍。第 1 格承接上一段结尾，最后一格钩住下一段；
  每格都有目标→阻碍→行动→结果，禁止纯表情/纯风景空镜}}

每个面板必须包含可见的身体动量和强烈的情绪张力。避免完全静态的姿势。

{{镜头语言：推轨/过肩/反应镜头/情绪特写/景深变化}}

{{简报③：局部区域 + 环境锚点（元素1 用于第 1-2 格，元素2 用于第 3-5 格，元素3 用于结尾定格）}}

标注颜色系统：红色箭头 = 身体运动；蓝色箭头 = 摄影机运动；绿色 = 取景笔记；
橙色 = 灯光方向；紫色 = 声音/情感强调；黑色文本 = 简短镜头笔记和面板标签。

无时间戳。
```

### ④ 视频提示词（每段一条，喂图生视频模型）

结构：**【参考图】清单强制放正文最前**，先声明用什么图，再讲怎么拍：

```
【参考图】
[图1·第N段分镜] —— 视觉叙事来源：节拍顺序、镜头切换、情绪递进全部以它为准。
[图2·{{角色名}}身份板] —— 身份锁：外貌、服装、轮廓以此为准，全程不变。
[图N·{{场景名}}场景] —— 空间基准：动线、光源、结构以它为准，不另造空间。
[图N·{{道具名}}道具] —— 器形锁：材质、比例、本段状态以它为准。

遵循 [图1·第N段分镜] 的全部 {{8}} 个节拍，整体氛围从{{情绪A}}递进到{{情绪B}}。
只读取故事板中的场景、角色动作、镜头顺序和情绪，不要把故事板上的文字、箭头、
颜色标记、面板边框、标题、注释或符号生成到视频里。

分秒节拍表（共 {{时长}} 秒，跟着故事板格子走）：
第 0–3 秒（第 1 格）：{{动作}}；
第 3–6 秒（第 2 格）：{{动作}}；
……
第 {{X}}–{{时长}} 秒（第 {{末格}} 格）：{{收尾动作}}，静谧定格。

{{转场与承接：1-2 个具体转场例子；开头承接上一段，结尾钩住下一段}}

保持与 [图2·{{角色名}}身份板] 相同的绝对核心主体身份，不要改变外貌、服装、轮廓。
动作流：{{5-6 个带质感词的动作细节：反光、肌理、飘动、震颤、光泽、呼吸起伏、湿润}}。

环境：以 [图N·{{场景名}}场景] 为唯一空间基准——{{局部区域动线}}，不要另造空间结构。
电影艺术风格镜头能量：{{4-5 种镜头技法}}。

最终节拍（{{情绪词}}）定格在{{机位与光线}}。画面静谧定格 1 秒。
```

每条视频的复制包头部还带参数建议块：

```
【参数建议】
  分辨率：480p（推荐起步——出片快、便宜，先验动作和转场对不对）
  时长：15 秒　｜　画幅：16:9
  动作和转场满意后，再用 720p / 1080p 重出定稿
```

### ⑤ 真实产出示例（节选）

《偷瓶降雨》项目第 4 段「天罚定格」的分秒节拍表——每秒段都落在故事板的格子上，出完片逐格对照检查：

```
分秒节拍表（共 15 秒，跟着故事板格子走）：
第 0–2 秒（第 1 格）：上段天际金光炸裂，雷符如锁链自云端压下，缠住少年持瓶的手臂；
第 2–4 秒（第 2 格）：金色「贼」字烙上额头，焦烟腾起，他咬紧牙关抱瓶的手没有松半分；
第 4–6 秒（第 3 格）：帝君隔门望向雨中那道身影，抬手至半——停住，指尖抵着门框；
第 6–9 秒（第 4 格）：流民陆续走出屋檐仰面接雨，有人跪进水洼溅起水花，无人回头看一眼天上；
第 9–11 秒（第 5 格）：少年落地单膝触地，以空瓶拄地撑住身体，瓶身灰白黯淡；
第 11–12 秒（第 6 格）：扶瓶缓缓站起站得笔直，雨水顺下颌成线滴落，额上金印在雨里发亮；
第 12–14 秒（第 7 格）：镜头缓推至他闭眼的脸，雨声最大的一格，身后人间灯火次第亮起；
第 14–15 秒（第 8 格）：他抱空瓶立于返青田埂，炊烟升起的远景渐黑，全片最终定格。
```

## 两条工作路径

| | 手动模式（默认） | 自动模式 |
|---|---|---|
| 谁出图 | 你自己贴提示词到画布（即梦/可灵/Gemini…） | agent 直接调模型 |
| 交付 | 一次性生成全套提示词 + `复制粘贴/` 纯文本包，照 `0-操作顺序.txt` 逐步贴，**不用中途回来等验收** | 逐张出图给用户确认后再往下 |
| 适合 | 大多数人、任意画布 | 已接好生图 API 的用户 |

## 十个阶段

```
0 立项问答 → 1 情节(3选1) → 2 歌词(3选1) → 3 画风锁
     → 4 人物 → 5 场景 → 6 道具 → 7 分镜(9/12宫格) → 8 视频 → 9 交付
```

每阶段产出落盘、状态写进 `进度.json`，随时说「继续我的 MV」断点续做；改前面的阶段会主动告诉你哪些下游产物失效。

## 项目产物结构

```
mv-<项目名>/
├── 进度.json              ← 状态机，唯一事实来源
├── 全部提示词.md           ← 总索引
├── 使用说明.md
├── 1-情节/ ~ 8-视频/       ← 各阶段定稿与提示词
├── 复制粘贴/              ★ 用户主要用这个（0-操作顺序.txt 是入口）
├── 素材/                  ← 出的图和视频（人物/场景/道具/分镜/视频/）
└── 模板/
```

## 目录（本仓库）

```
├── SKILL.md               ← skill 入口（含核心铁律）
├── references/            ← 十个阶段的详细规范（问答/情节/歌词/画风/人物/场景/道具/分镜/视频/交付）
├── scripts/新建项目.py     ← 项目骨架一键创建
└── 使用说明.md             ← 面向使用者的完整说明
```

## 设计铁律（摘要）

1. 先问再生成，参数没核对完不开工
2. 创作主张让用户选（情节、画风、**时长**），技术参数替用户定
3. 画风是全局锁
4. **参考放最前**：提示词正文用到参考图时，【参考图】清单必须在正文最前面，逐张写明用途
5. **手动模式不等图**：阶段 4→8 提示词一次性生成再交付，验收图片是出图后的可选服务
6. 状态写在 `进度.json`，随时可续做
