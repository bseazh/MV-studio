# 命名与占位符规范

对所有阶段生效。原则只有一条：**名字要人能看懂**。编号给机器，名字给人，两样都要有。

## 一、文件命名

### 媒体文件

格式：`<类型>-<名字>-v<版本>.<扩展名>`

| 类型 | 示例 | 存在哪 |
|---|---|---|
| 人物 | `人物-林夏-v1.png` | `素材/人物/` |
| 场景 | `场景-便利店-v1.png` | `素材/场景/` |
| 道具 | `道具-湿伞-v1.png` | `素材/道具/` |
| 分镜 | `分镜-第1段-v1.png` | `素材/分镜/` |
| 视频 | `视频-第1段-v1.mp4` | `素材/视频/` |

- 版本从 `v1` 起，重新生成递增成 `v2`、`v3`，**不覆盖旧文件**。经常是第一版某个局部反而更好。
- 同一场景出多视角时，视角写进名字：`场景-便利店-全景-v1.png`、`场景-便利店-柜台-v1.png`。
- 名字里有空格一律换连字符。

### 分段写法

**一律写「第N段」。** 不写 `seg-01`、`段落1`、`S1`、`segment-1`。

提示词文件、复制包文件、媒体文件、`进度.json` 里全部统一，不许一个地方一种写法。

## 二、占位符

两类，性质完全相反，搞混就出事。

| 类型 | 写法 | 谁填 | 交付时 |
|---|---|---|---|
| **变量占位符** | `{{双花括号}}` | 你（写提示词时） | **必须 0 残留** |
| **引用占位符** | `[图N·名字]` | 用户（上传图片时） | **必须原样保留** |

`{{角色名}}` 残留到用户手里 = 提示词废了。
`[图2·林夏身份板]` 被你好心替换成「林夏-v1.png」= 模型读不懂，身份锁失效。

### 2.1 变量占位符 `{{...}}`

模板里的填空位，写提示词时全部换成实际内容。常见的：

```
{{画风描述}}    从 3-画风/画风锁.md 逐字复制
{{镜头风格}}    镜头表现风格描述
{{概念方向}}    MV 概念方向及其执行规则
{{时长}}        本段秒数
{{格数}}        9 或 12
{{出场角色}}    本段出场角色名
```

**交付前强制自检：**

```bash
grep -rn '{{' 复制粘贴/
```

有输出就是没填完，回去补。这一步不许跳过。

### 2.2 引用占位符 `[图N·名字]`

格式三部分：

```
[图1·便利店场景]
 │  │   └─ 中文名字，给人看的，让用户一眼知道这是哪张
 │  └──── 中点分隔
 └─────── 编号，对应上传顺序，这部分才真正起作用
```

**编号约定**（固定，不要乱改）：

| 槽位 | 内容 | 用在哪 |
|---|---|---|
| `[图1·...]` | 主参考 —— 分镜阶段是场景图，视频阶段是分镜图 | 阶段 6、7 |
| `[图2·...]` | 角色身份板 | 阶段 6、7 |
| `[图3·...]` | 道具图 | 阶段 6、7（有道具时） |
| `[图4·...]` 起 | 追加角色或追加场景 | 多角色段落 |

**每个用到引用占位符的文件，顶部必须有这张对照表：**

```
【参考图清单 · 按顺序上传】
  [图1·便利店场景]    场景-便利店-柜台-v1.png
  [图2·林夏身份板]    人物-林夏-v1.png
  [图3·湿伞道具]      道具-湿伞-v1.png
```

顺序就是上传顺序。手动模式下文件名那列写用户自己存的名字，自动模式下写项目内真实相对路径。

### 2.3 待办占位符 `[待出图·...]`

前置产物还没有、但提示词已经要写的时候，显式标记，不要用自然语言糊弄：

```
[待出图·林夏身份板还没生成，出图后回填图2槽位]
```

交付前自检：

```bash
grep -rn '待出图' 复制粘贴/
```

有残留就明确告诉用户「这几条要等 X 出图后才能用」，不要默默交付。

## 三、各画布/模型适配

开场问过用户用哪个画布，按表调整。拿不准用通用写法。

| 目标 | 写法 | 注意 |
|---|---|---|
| 通用 / 不确定 | `[图1·名字]` | 清单里写明上传顺序 |
| Gemini / nano banana | `[图1·名字]` | 上传顺序必须和编号一致 |
| 即梦 / 可灵 | `[图1·名字]` | 它们界面显示「参考图 1/2」，编号正好对上 |
| 英文界面模型 | `[Image 1 · 名字]` | 编号用英文，名字保留中文 |
| Midjourney | 图片 URL 放最前 + `--cref` 锁角色 | 槽位概念弱，靠参数锁 |
| 视频模型 | `[图1·...]` = 分镜图或首帧，`[图2·...]` = 角色图 | 多数只吃 1-2 张，超了要取舍 |

同一个项目里只用一种写法，不混用。

## 四、不要用占位符的地方

- **画风描述**：必须逐字写全，不要写 `[见画风锁]`。模型读不到你的文件。
- **动作、情绪、环境细节**：必须写成具体文字，不要留占位符让用户自己填。
- **角色外貌**：分镜和视频提示词里，除了 `[图2·...]` 的身份锁，还要把关键外貌特征（发型轮廓、服装轮廓、年龄感）写成文字。图片引用会漂，文字约束是保险。
