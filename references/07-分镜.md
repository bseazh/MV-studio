# 阶段 7 · 故事分段 + 9/12 宫格分镜

信息量最大的一步，分四小步。

## 6.1 故事骨架 → `7-分镜/故事骨架.md`

先定分段：总时长 ÷ 每段秒数。常用 15 秒一段（60 秒歌 = 4 段）。段数写进 `进度.json`。

```markdown
# 故事骨架

- **一句话故事**：<概括整首 MV>
- **情感弧线**：<如 孤独→挣扎→释放→升华>
- **视觉风格主轴**：<一句话>
- **最终定格画面**：<整首 MV 收尾那一帧>

## 歌曲指纹

- 核心主题：这首歌真正讲的是什么
- 关系类型：我与谁/什么的关系
- 情绪动词：等待、逃离、靠近、放下
- 歌词意象：
- 可视化母题：
- 需要避免的俗套：

## 分段表

| 段 | 时间 | 出场角色 | 剧情（想做什么→阻碍→行动→结果） | 歌词钩子 | 视觉转译 | 道具状态 | 入场承接 | 出场钩子 |
|---|---|---|---|---|---|---|---|---|
| 第1段 | 0:00–0:15 | | | | | | | |
```

「入场承接 / 出场钩子」两列是连续性的命脉：**每段第一格必须承接上一段的出场钩子，最后一格必须形成下一段的钩子。不要把任何一段画成独立海报。**

## 6.2 每段节拍

9 格写 6-8 个节拍，12 格写 8-10 个（一个节拍对应 1-2 格）。每个节拍是一个具体视觉画面，30-50 字。

### 硬规则

- 节拍由**剧情**驱动，不是由歌词驱动。歌词只提供情绪温度，不逐字直译
- 每个节拍必须服务本段剧情目标、歌词钩子和动作类型，禁止纯表情/纯情绪描写
- 动作不必一味夸张，可以细腻，但必须有明确行为、环境反馈或意象变化
- 不要连续重复上一段的主动作。上段用过旋转/跳跃/落地，本段必须换成道具互动、空间移动、关系动作、环境事件、镜头事件或意象变化
- 每个节拍信息必须不同，不允许只是同一个动作换角度
- **禁止这些低信息画面**：呆坐沉思、望向远方发呆、缓步行走无目的、纯风景空镜、重复跳跃、重复旋转

每段节拍写完顺手记下：核心冲突/物理事件、本段道具/环境使用方式、本段要避免重复的动作。

## 6.3 导演简报 → `7-分镜/第N段-简报.md`

出图提示词之前先写简报，三段式，段间用 `---` 分隔。

**段落 1 — 场景定调与角色描述（2-3 句）**
格式：为故事板创建一个`[场景的明确局部区域，例如入口左侧、柜台前景、玻璃走廊中段、舞台边缘、窗边近景]`，专注于`[核心视觉焦点与情绪基调]`。使用参考图像（`<角色名>`）作为核心角色。角色在本段中的状态/情绪：…

**段落 2 — 动作序列**
按节拍描述 N 个面板的事件推进。要求：
1. 第一个动作承接上一段出场钩子
2. 每个动作体现所选镜头表现风格的特征
3. 符合所选 MV 概念方向
4. 动作之间有目标、阻碍、行动、结果，或情绪/意象递进
5. 包含 6-8 个具体动作描述，用顿号连接，每个必须带来新的信息、位置、道具、关系或环境变化
6. 避免重复旋转/跳跃/落地/抬手/灯光爆发
7. 最后一句描述结尾定格画面，并明确它如何成为下一段的衔接锚点

**段落 3 — 环境描述（1-2 句）**
格式：局部区域：`[明确写出环境图中的哪个区域/角落/动线]`。环境锚点：`[元素1]`用于第 1-2 格动作，`[元素2]`用于第 3-5 格情绪变化，`[元素3]`用于结尾定格。

### 画面张力强制要求

- 不要把本段画成重复姿势集合；每个面板必须表现事件推进：目标 → 阻碍 → 行动 → 结果
- 动作可以大也可以细腻；重点是每格信息不同、角色状态或空间关系发生变化
- 每个面板的角色必须有明确姿态、位置、视线、道具或环境关系变化，**禁止连续两个面板信息相似**
- 环境必须参与叙事：物件被踢飞/打碎/吹散、光影因动作而剧烈变化、空间因角色运动而产生透视变化
- 多角色段落必须说明每个角色的独立动作、视线方向、相互距离和关系变化，不要只写「众人一起行动」
- 有环境参考图时，环境描述必须锁定该图的具体局部区域，说明角色在该局部的前景/中景/远景位置、入口/出口方向、光线方向、关键道具，以及这些元素在哪几格参与动作

## 6.4 宫格提示词 → `7-分镜/第N段-提示词.md`

先问用户要 **9 宫格还是 12 宫格**（9 格节奏松、单格信息足；12 格节奏密、适合卡点和快剪）。

```
{{画风描述}}

【参考图】
[图1·{{场景名}}场景] —— 参考它的空间结构、光线方向、材质、主色调和关键道具。环境图只是场景锚点，不要机械复制成静态背景；每个小分镜仍必须根据本段动作发生变化。必须让故事板明确发生在该图中的某一个局部区域/动线，而不是泛泛借用气氛。每个面板都要保持该局部区域的空间连续性：角色相对前景/中景/远景、入口/出口、光源和关键道具的位置必须可读。
[图2·{{角色名}}身份板] —— 优先参考人物气质与外貌特征，但保持故事板草图应有的简化表达。
[图3·{{道具名}}道具] —— 本段道具状态：{{查状态表}}

{{简报段落1}}

16:9 故事板表格，{{格数}} 个电影风格面板。实际故事板绘图必须仅为黑白：粗糙的铅笔线条、最小细节、快速手势绘图能量、简单的解剖结构构建以及强烈的轮廓可读性。保持艺术作品轻量、动态且未完成，就像早期的动作预览。

{{简报段落2}}

每个面板必须包含可见的身体动量和强烈的情绪张力。避免完全静态的姿势。

{{镜头风格的镜头语言描述}}

{{简报段落3}}

标注颜色系统：红色箭头 = 身体运动 / 肌肉发力方向；蓝色箭头 = 摄影机运动；绿色标记 = 取景 / 构图笔记；橙色标记 = 灯光方向；紫色标记 = 声音 / 情感强调；黑色文本 = 简短镜头笔记和面板标签。

无时间戳。
```

宫格图是**黑白铅笔草图**，不是成片画面。画风锁在这里的作用是约束角色造型和空间气质，不是让它出彩色成片——如果模型出了彩色精修图，说明「仅为黑白、粗糙铅笔线条」被稀释了，往前提。
