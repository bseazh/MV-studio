# 阶段 8 · 视频提示词

每段一条，喂给图生视频模型（Seedance / 可灵 / 即梦 / Veo / 百炼 / KIE 都适用）。

**输入图一个都不能少**，每条视频提示词的参考图清单必须齐：

- `[图1·第N段分镜]` —— 视觉叙事来源
- `[图2..·<角色名>身份板]` —— 本段**每个**出场角色都要挂，一个不落
- `[图N·<场景名>场景]` —— 本段出现的**每个**场景锚点图都要挂
- `[图N·<道具名>道具]` —— 核心道具图必须挂

只挂人物不挂场景和道具是**实际踩过的坑**：空间结构和器形会漂，用户会要求全部重写。手动模式下本阶段提示词与阶段 7 同一批次产出（引用分镜图的槽位名即可，不等分镜图出完）。

## 输出 → `8-视频/第N段-提示词.md`

**纯提示词正文，不加标题、编号、markdown 标记或任何前缀说明。** 参考图清单打头，然后自然连贯的段落，总长 400-600 字。

### 段落 1 — 【参考图】清单（必须放正文最前面）

```
【参考图】
[图1·第N段分镜] —— 视觉叙事来源：节拍顺序、镜头切换、情绪递进全部以它为准。
[图2·<角色名>身份板] —— 身份锁：外貌、服装、轮廓以此为准，全程不变。
[图N·<场景名>场景] —— 空间基准：动线、光源、结构以它为准，不另造空间。
[图N·<道具名>道具] —— 器形锁：玉质/材质、比例、本段状态以它为准。
```

逐张写一句用途，本段用不到的图不列。清单之后紧接一句：只读取故事板中的场景、角色动作、镜头顺序和情绪，**不要把故事板上的文字、箭头、颜色标记、面板边框、标题、注释或符号生成到视频里**。

### 段落 2 — 故事板锚定（1-2 句）

说明遵循的节拍数量和整体氛围递进方向。必须体现所选 MV 概念方向的执行规则。

### 段落 3 — 分秒节拍表（必须逐条写，不许省）

把段落时长拆成明确的时间表，每条格式：**第 X–Y 秒（故事板第 N 格）：做什么动作**。

- 一条对应 1-2 格，总秒数必须加总等于段时长（如 4 段 × 15 秒，每条表加总 = 15）
- 动作描述直接取自该段简报的节拍序列，让用户能对照「第几秒跟着哪一格」检查出片
- 格子编号按分镜图「从左到右、从上到下」数

写法示例：

```
分秒节拍表（共 15 秒，跟着故事板格子走）：
第 0–3 秒（第 1 格）：冷金天光斜切入殿，少年立于台阶下仰视高台；
第 3–6 秒（第 2 格）：帝君踱至香案后供瓶，瓶身微光初亮；
……
第 13–15 秒（第 8 格）：瓶光微颤，天色转白，定格。
```

### 段落 4 — 转场与承接（2-3 句）

用什么转场（匹配剪辑、硬切、动作跟随等），**举出 1-2 个具体转场例子**（如「从雨滴砸在伞面的闪光无缝衔接到玻璃上的水痕」这种程度的具体）。必须体现连续性要求：开头承接上一段，结尾能接到下一段。

### 段落 5 — 角色与动作流（3-4 句）

以「保持与 [图2·<角色名>身份板] 相同的…」开头锁定角色身份，明确不要改变外貌、服装、轮廓。多角色时逐一说明每个角色的动作、视线和相互距离。然后列举 **5-6 个具体的、有视觉冲击力的动作细节**。

动作描述必须带**质感词**：反光、肌理、飘动、震颤、光泽、呼吸起伏、湿润。

### 段落 6 — 环境与镜头（2-3 句）

以「环境：」开头，明确引用场景图里的主场景、分视角和局部区域/动线，**不要泛写氛围**。然后以「电影艺术风格镜头能量：」开头列举 4-5 种具体镜头技法。

技法要具体：极微距、低角度仰拍、环绕运镜、长焦压缩、过肩视角、手持追焦、失焦重聚焦。

### 段落 7 — 最终节拍（1-2 句）

以「最终节拍（<情绪词>）」开头，具体描述定格画面的光线、构图和情绪，以「画面静谧定格 1 秒」结尾。

## 通用硬约束

- **【参考图】清单必须在正文最前面**，先声明用什么图，再讲怎么拍
- **分秒节拍表必须落在故事板格子上**，每秒段都有归属，不许只写「前松后紧」这种模糊节奏
- 整体语气像专业导演的拍摄指令，充满画面感
- 转场要有具体例子，不要泛泛说「流畅转场」
- **故事板是导演参考图，不是最终画面素材。** 最终视频画面必须干净：禁止出现任何文字、字幕、英文单词、箭头、颜色标注、面板标签、边框、UI 控件、手写注释、制作说明或故事板纸张质感
- 道具要按状态表描述本段状态，并给它质感词和动态

## 极简备用版

有些模型（尤其 API 版、字数吃紧的）不吃长提示词，用这个压缩版：

```
【参考图】
[图1·第N段分镜] —— 视觉叙事来源，节拍顺序与镜头切换以它为准。
[图2·{{角色名}}身份板] —— 身份锁，外貌服装全程不变。
[图N·{{场景名}}场景] —— 空间基准。{{本段还挂了什么图就继续列}}

分秒节拍表（共 {{时长}} 秒）：{{逐条「第 X–Y 秒（第 N 格）：动作」，加总=时长}}。故事板中的箭头、颜色标记、手写注释、面板编号、标题文字、边框和制作说明都只是导演标注层，绝对不能出现在最终视频画面中。

保持与 [图2·{{角色名}}身份板] 相同的绝对核心主体身份。不要改变外貌、服装、轮廓。整个过程中持续展现极具观赏性的动作流：{{3-4 个动作提示}}

环境：{{局部区域与关键道具}}。电影艺术风格镜头能量：{{4-5 种镜头技法}}。

最终节拍（{{情绪词}}）在最具记忆点的机位和光线下完成最终姿态，画面静谧定格 1 秒。
```

## 交付

存 `素材/视频/视频-第N段-v1.mp4`，路径回写 `进度.json`。按 `09-交付.md` 生成 `复制粘贴/5-视频-第N段.txt`。

复制包里必须带 **【参数建议】块**（分辨率 / 时长 / 画幅，480p 推荐起步），格式见 `09-交付.md`。

全部段落做完写 `"stage": "完成"`，给用户一份清单：每段的分镜图、视频文件、总时长、缺哪几段。
