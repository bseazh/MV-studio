# 阶段 5 · 场景提示词

## 先定场景数

默认 **2-3 个核心场景**，除非歌词明确需要更多。每个场景要能支撑多个段落复用。

先写清单，每个字段一句短句，顶部要有一条贯穿全片的**世界观**（核心空间、时代感、材质、光线和情绪基底），分镜阶段会反复引用：

```markdown
# 场景包

**全片世界观**：<一句话>

## <场景名称>

- **情绪用途**：<承载什么情绪>
- **视觉元素**：<环境元素、色彩、光线、材质、关键道具>
- **使用段落**：第1段、第2段
```

## 提示词 → `5-场景/<名字>-提示词.md`

每个场景可以出 1 张主视角，也可以出多视角（全景 / 中景动线 / 局部区域）。多视角时同一场景**必须保持一致的空间结构、关键道具、主色调、材质和光线逻辑**，只改变镜头位置、景别、空间层次或道具关注点。多视角时视角写进文件名：`场景-便利店-全景-v1.png`。

```

视角类型：{{视角名，如 全景建立镜头 / 中景动线 / 局部特写区域}}
```

## 关键提醒

环境图的作用是**锚点，不是背景板**。分镜阶段引用它时，必须锁定到图里的某个具体局部区域（入口左侧、柜台前景、玻璃走廊中段、舞台边缘、窗边近景），而不是泛泛借用气氛。所以这一步写「视觉元素」就要够具体，让后面有东西可以指。
