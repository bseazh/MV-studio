# 阶段 2 · 歌词

## 前提

阶段 1 的 `1-情节/定稿.md` 必须已经存在。歌词是从情节里长出来的，**不要在情节定稿前写歌词**。

时长、行数、语言、人声在阶段 0 的参数确认单里已经定好，不要重复问。

## 目标

基于选定的情节，给出**三个风格明显不同**的歌曲方向，每个带一段示例歌词，让用户三选一。

三个方案的差别要落在**音乐气质**上（而不是故事上，故事已经定了）：
比如同一个情节可以做成梦幻飘的、城市暖的、摇滚炸的三种。

## 输出 → `2-歌词/三个方案.md`

```markdown
## 方案 A · <标题（4-8字，有感觉的名字）>

- **感觉**：<一句话，15 字以内>
- **风格标签**：<英文，逗号分隔，3-5 个>

<歌词正文>
```

### 歌词硬约束

- 目标 60 秒以内 → **5-6 行实际歌词**（不含标签行）
- 结构只能是：`[Verse]` 2-3 行 + `[Chorus]` 3 行 + `[End]`
- 每行 7-14 个字
- 不要写 `[Pre-Chorus]`、`[Bridge]`、`[Verse 2]`
- 不要重复副歌，不要第二段主歌，不要长尾

### 风格标签硬约束

- 必须英文、英文逗号分隔，不要中文、不要顿号
- 要用出歌模型认得的风格词，可覆盖乐器 / 情绪 / 速度 / 人声类型
- 示例：`Indie Pop, Dream Pop, Lo-fi, Ethereal, Female Vocal`
- 示例：`R&B, Emotional, Piano, Slow Tempo, Melancholic`
- 示例：`Rock, Energetic, Guitar Solo, Male Vocal, Upbeat`

### 质量要求

- 三个方案风格**明显不同**，不能只是换词
- 必须贴着 `1-情节/定稿.md` 的事件走，保留其中最有辨识度的场景、人物状态、情绪转折
- 歌词行数按参数确认单：30 秒 3-4 行、60 秒 5-6 行、90 秒 7-8 行
- 歌词要有具体的画面和意象，避免「我爱你」「向前走」这类空泛词
- 语言自然，像真实歌曲，不像作文

## 用户选定后 → `2-歌词/定稿.md`

```markdown
# <歌名>

**风格标签**：<标签>
**预计时长**：<秒>

## 歌词

<正文>

## 情绪与意象备忘

- 核心情绪：
- 关键意象：
- 情绪弧线：<如 孤独→挣扎→释放>
```

最后那段备忘很重要，后面每个阶段都会回来读它。

更新 `进度.json` 的 `lyrics` 和 `stage: 3`。
