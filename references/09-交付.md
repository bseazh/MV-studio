# 阶段 9 · 交付

每完成一个阶段就顺手更新一次，不要等全做完才来做。

## A. 复制粘贴包 `复制粘贴/`

用户主要就用这个目录。每个文件对应画布上的一次操作，**打开就能全选复制**。

### 格式（所有文件统一）

`.txt` 纯文本。图像类文件固定三段；视频文件在参考图清单前多一段【参数建议】：

```
════════════════════════════════════════
用途：角色身份板 · 林夏
目标：图像模型（画布）· 16:9
════════════════════════════════════════

【需要上传的参考图 · 按顺序】
  无（纯文生图，直接粘贴提示词即可）

【复制下面两条分隔线之间的内容】
──────────── 复制开始 ────────────
画风：精致写实动漫风格。细腻五官、高质感光影……

创建一张艺术性的 16:9 角色身份板。
……
──────────── 复制结束 ────────────

【出图后】
  存成：人物-林夏-v1.png
  放进：素材/人物/
  下一步哪里会用到：4-分镜-第1段.txt 的 [图2·林夏身份板]
```

**视频文件（`5-视频-第N段.txt`）必须在参考图清单之前加【参数建议】：**

```
【参数建议】
  分辨率：480p（推荐起步——出片快、便宜，先验动作和转场对不对）
  时长：15 秒　｜　画幅：16:9
  动作和转场满意后，再用 720p / 1080p 重出定稿
```

时长写本段的秒数（与分段表一致）。分辨率默认推荐 **480p 起步**：第一版几乎必返工，先用便宜的验证节奏，定稿再升清晰度。

要点：

- 分隔线之间**只有提示词正文**，没有标题、没有说明、没有 markdown 符号。全选复制不带杂质
- 参考图清单和参数建议在分隔线**外面**，不要混进提示词；但提示词正文内部如果用到参考图，**【参考图】清单要放在正文最前面**（见 `08-视频.md` / `07-分镜.md` 的模板）
- 「出图后」三行把整条链串起来：存成什么名、放哪、下一步谁用它。省得用户自己对
- 用 `.txt` 不用 `.md`，有些编辑器会渲染 markdown，复制出来格式就乱了

### 有参考图时的清单写法

```
【需要上传的参考图 · 按顺序】
  第1张  [图1·便利店场景]    场景-便利店-柜台-v1.png
  第2张  [图2·林夏身份板]    人物-林夏-v1.png
  第3张  [图3·湿伞道具]      道具-湿伞-v1.png

  ⚠ 上传顺序必须和编号一致，传错顺序模型会认错人
```

提示词正文里的 `[图1·...]` 原样保留，**不要替换成文件名**。

### 文件清单与顺序

```
0-操作顺序.txt       ← 先看这个
1-人物-<名字>.txt
2-场景-<名字>.txt
3-道具-<名字>.txt
4-分镜-第N段.txt
5-视频-第N段.txt
```

编号前缀是**用户出图**的执行顺序：人物、场景、道具可并行，分镜必须等前三个出完图（要拿它们当上传参考），视频必须等分镜出完图。

注意区分：这是**出图顺序**，不是提示词的产出顺序。手动模式下所有提示词文件（含分镜、视频）在交付时就一次性全部生成好，用户自己照这个顺序贴，不需要中途回来找你；「分镜等图」卡的是用户贴提示词的动作，不是你写提示词的进度。

### `0-操作顺序.txt`

```
MV 项目：<歌名>
画风：<画风名>　｜　镜头风格：<名称>　｜　概念方向：<名称>
分段：<N> 段 × <M> 秒　｜　宫格：<9 或 12> 格

执行顺序
────────────────────────────────────────
第 1 步  出人物图   1-人物-*.txt      共 N 张   → 存成 人物-<名字>-v1.png
第 2 步  出场景图   2-场景-*.txt      共 N 张   → 存成 场景-<名字>-v1.png
第 3 步  出道具图   3-道具-*.txt      共 1 张   → 存成 道具-<名字>-v1.png
第 4 步  出分镜图   4-分镜-第N段.txt  共 N 张   → 需上传前三步的图
第 5 步  出视频     5-视频-第N段.txt  共 N 段   → 需上传分镜图 + 人物图，分辨率建议 480p 起步

注意
────────────────────────────────────────
· 第 4 步之前建议先确认人物的脸和服装对了（可以把图丢回来让我检查），这一步放水后面每一格都会歪
· 视频：先按 480p 出，动作、转场、人物对了再用 720p/1080p 重出定稿；每段出片前看一眼提示词里的分秒节拍表，对照检查
· 分镜图是黑白铅笔草图，不是成片画面。出来是彩色精修图说明提示词被稀释了
· 分镜图上的箭头和标注只是导演层，视频提示词里已写明不要生成进画面
· 重新生成请递增版本号（v2、v3），不要覆盖旧图
· 提示词里的 [图1·xxx] 原样保留，不要替换成文件名
```

## B. 总索引 `全部提示词.md`

一个文件看到全貌。每条只放文件链接和状态，**不要全文重复**。

```markdown
# <歌名> · 全套提示词

<创作描述原文>

| 阶段 | 对象 | 提示词 | 复制包 | 产出图 | 状态 |
|---|---|---|---|---|---|
| 歌词 | <歌名> | 2-歌词/定稿.md | — | — | ✅ |
| 画风 | <画风名> | 3-画风/画风锁.md | — | — | ✅ |
| 人物 | 林夏 | 4-人物/林夏-提示词.md | 复制粘贴/1-人物-林夏.txt | 素材/人物/人物-林夏-v1.png | ✅ |
| 分镜 | 第1段 | 7-分镜/第1段-提示词.md | 复制粘贴/4-分镜-第1段.txt | — | ⏳ 待出图 |
```

状态只用三种：✅ 已完成 / ⏳ 待出图 / ⬜ 未开始。

## C. 交付前自检（强制，不许跳）

```bash
cd <项目根>
grep -rn '{{' 复制粘贴/ && echo "❌ 有变量占位符残留，必须补完"
grep -rn '待出图·' 复制粘贴/ && echo "⚠️ 有待办占位符，要告诉用户等什么"
ls 复制粘贴/
```

- 变量占位符残留 → 必须回去补完才能交付
- 待办占位符 → 可以交付，但要明确告诉用户哪几条要等什么
- 人工再扫一眼三件事：
  1. 每个用到 `[图N·...]` 的文件，分隔线外有没有参考图清单，提示词**正文最前面**有没有【参考图】块
  2. 视频文件有没有【参数建议】（分辨率 480p 起步 / 时长 / 画幅），提示词里有没有分秒节拍表且秒数加总等于段时长
  3. 视频提示词挂的参考图是否齐全：分镜 + 本段全部出场角色 + 本段全部场景 + 道具，缺一类就补

## D. 自动模式额外要做的

手动模式到 C 就结束。自动模式继续：

1. 按 `0-操作顺序.txt` 的顺序逐步调用，**不要跳步并发**——分镜依赖前面的图
2. 每步出图给用户看，**等确认再往下**。人物图尤其要确认，这是整条链的身份锚点
3. 每次调用按 SKILL.md 规范落盘 + 写 `素材/调用记录/` + 回写 `进度.json`
4. 失败重试最多 2 次，还失败就停下来报告，不要静默跳过
5. 全部完成后更新 `全部提示词.md` 的状态列，给用户最终清单

自动模式**也要出复制粘贴包**，因为用户随时可能想手动重跑某一格或换个画布试效果。
